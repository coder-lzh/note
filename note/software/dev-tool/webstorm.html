Webstorm 关闭自动保存功能 ​

webstrom 设置方法同样适用于几乎所有 JetBrains 系列编辑器

1、关闭自动保存：打开设置 -- 外观 & 行为 -- 系统设置 -- Synchronization

2、修改的文件，标签 * 号标识

打开设置 -- 编辑器 -- 常规 -- Editor Tabs -- 选项卡外观

vue项目@/xx/xx相对路径不能跳转到对应文件 ​

跟目录(与src同级)下创建jsconfig.json

json
{
  "compilerOptions": {
    "types": [
      "@dcloudio/types"
    ],
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "src/*"
      ]
    },
    "target": "ES6",
    "allowSyntheticDefaultImports": true
  },
  "include": [
    "src/**/*"
  ],
  "exclude": [
    "node_modules"
  ]
}
