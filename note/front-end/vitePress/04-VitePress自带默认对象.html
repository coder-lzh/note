04-VitePress自带默认对象 ​

这里主要介绍VitePress内置的对象，干什么用，如何获取和使用。

路由相关 ​

获取当前页面路由对象 ​

vue
<script setup>
    import { useRoute } from 'vitepress'
    const route = useRoute()
    console.log(route)
    console.log(route.path) // 当前页面路径
</script>
