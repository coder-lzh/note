01-HTTPS证书 ​

Openssl证书 ​

下载：Openssl 然后 配置环境变量

注意：需要有外网环境才可以打开官网，有两个版本，一个Light版（5M），一个全量版(217M)。正常情况下Light版就够用。

Light版 网盘地址：https://wwd.lanzout.com/ixkzU282pa3g

下面的命令是生成证书，一路回车就行，先执行第一条命令，再执行第二条

shell
openssl genrsa -out key.pem 2048
openssl req -new -x509 -key key.pem -out cert.pem -days 365
